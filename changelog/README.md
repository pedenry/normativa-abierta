# Registro de cambios

Convención: `AAAA-MM-DD-usuario-titulo-corto.tipo.md`, con `tipo` = `intent`, `changelog` o `handoff`.

Cada registro incluye fecha ISO con zona, título, tipo, usuario GitHub verificado, solicitante y ejecutor separados, herramienta/modelo sólo si está validado, fuentes/commits, estado y resultados. No se incluyen conversaciones, prompts, rutas privadas, secretos ni respuestas de tests.

Un registro puede referenciar el último commit observado; su propio commit se consulta en el historial para evitar autorreferencia.
