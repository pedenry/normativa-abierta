# a0104 8.3  Uniones de tipo clavija

8.3  Uniones de tipo clavija
1
Dentro de la denominación de clavija se incluyen los elementos de fijación mecánicos siguientes:
clavos, grapas, pernos, pasadores y tirafondos.
