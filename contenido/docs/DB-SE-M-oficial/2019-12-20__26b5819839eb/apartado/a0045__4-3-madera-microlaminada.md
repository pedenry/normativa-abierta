# a0045 4.3  Madera microlaminada

4.3  Madera microlaminada
1
La madera microlaminada para uso estructural deberá suministrarse con una certificación de los
valores de las propiedades mecánicas y del efecto del tamaño de acuerdo con los planteamientos
generales de este DB.
