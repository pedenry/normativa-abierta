# a0087 5.1.5  Acabados superficiales

5.1.5  Acabados superficiales
Los acabados superficiales, especialmente pinturas, aplicados sobre los elementos constructivos dise-
ñados para acondicionamiento acústico, no deben modificar las propiedades absorbentes acústicas de
éstos.
