# a0056 3.1.4  Condiciones de diseño de las uniones entre elementos constructivos

3.1.4  Condiciones de diseño de las uniones entre elementos constructivos
Deben cumplirse las siguientes condiciones relativas a las uniones entre los diferentes elementos cons-
tructivos, para que junto a las condiciones establecidas en cualquiera de las dos opciones y las condicio-
nes de ejecución establecidas en el apartado 5, se satisfagan los valores límite de aislamiento especifi-
cados en el apartado 2.1.
