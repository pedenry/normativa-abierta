# a0089 7.3.2.3 Muros doblados

7.3.2.3 Muros doblados
1
Las dos hojas de un muro doblado (véase anejo A) se enlazarán eficazmente mediante conectores
capaces de transmitir las acciones laterales entre las dos hojas, con un área mínima de 300 mm²/m²
de muro, con conectores de acero dispuestos uniformemente en número no menor que 2 conecto-
res/m² de muro.
2
Algunas formas de armaduras de tendel pueden también actuar como llaves entre las dos hojas de
un muro doblado, por ejemplo las mostradas en la norma UNE-EN 845-3:2014.
3
En la elección del conector se tendrán en cuenta posibles movimientos diferenciales entre las hojas.
