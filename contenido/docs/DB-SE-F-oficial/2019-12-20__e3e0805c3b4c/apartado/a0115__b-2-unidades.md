# a0115 B.2 Unidades

B.2 Unidades
1
Se utiliza el Sistema Internacional de Unidades de Medida, SI.
2
Para los cálculos se recomienda el uso de las unidades siguientes:
- fuerzas y cargas:
kN, kN/m, kN/m²
- masa:
kg
- longitud:
m, mm
- tensiones:
N/mm²
- momentos:
kN ·m
3
A efectos prácticos se podrá considerar la siguiente correspondencia entre las unidades de fuerza de
los sistemas MKS y SI: 1 kilopondio [1 kp] = 10 Newton [10 N]
