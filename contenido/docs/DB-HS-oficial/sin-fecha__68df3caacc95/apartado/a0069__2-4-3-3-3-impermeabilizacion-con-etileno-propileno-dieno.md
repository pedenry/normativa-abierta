# a0069 2.4.3.3.3 Impermeabilización con etileno propileno dieno monómero

2.4.3.3.3 Impermeabilización con etileno propileno dieno monómero
1
Cuando la pendiente de la cubierta sea mayor que 15%, deben utilizarse sistemas fijados mecáni-
camente.
2
Cuando la cubierta no tenga protección, deben utilizarse sistemas adheridos o fijados mecánica-
mente.
3
Cuando se utilicen sistemas no adheridos, debe emplearse una capa de protección pesada.
