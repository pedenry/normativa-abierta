           3.2.5                                  Tolerancias
           (1)                        Las          tolerancias          de          dimensiones          y          masa          de          secciones          de          acero          laminado,          perfiles          tubulares
           estructurales      y      chapas       deberán       estar      de       acuerdo       con      este      Código      Estructural      y      con      el       Documento       de
           Evaluación     Europeo     (DEE)     correspondiente,     salvo    que     se    prescriban    tolerancias     más    exigentes.
           (2)                        Para     componentes    soldados,     deberán     aplicarse    las     tolerancias    que    se     establecen     en     este     Código.
           (3)                        Se     deben     utilizar     los     valores     nominales     de     las    dimensiones     para    el     cálculo    y    análisis     estructural.
